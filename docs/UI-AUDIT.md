# Аудит Shelf Studio — 10 октября 2026

## Цель и проверенный сценарий

Молдова, 20–30 SKU в день, фото для Shelf: непрозрачный JPG на чистом белом фоне, плотная прямоугольная обрезка без изменения пропорций. Поток: товары → кандидаты → выбранный исходник → подготовка → проверка упаковки и прав → экспорт.

Аудит проведён по коду, API-контрактам и рендеру на десктопе/телефоне. Автоматические браузерные проверки используют изолированный профиль и не меняют реальные партии пользователя. Требования самой программы Shelf к импорту проверяются отдельно в установленной версии Shelf.

## Сравнение вариантов

После исправления контрастности заголовков таблицы и пояснения поиска дополнительные проверки WCAG AA проходят в браузере на десктопе и телефоне.

1. **Управляемый поиск и профили подготовки — выбран и реализован.** Высокая польза для ежедневного процесса, без новой инфраструктуры или подписок. Полный охват остаётся доступным и включён по умолчанию; быстрый режим пользователь выбирает явно. Сервер проверяет режим и лимит до обращения к источникам.
2. **Последовательная проверка — реализована небольшая часть.** Кнопки навигации и подтверждения с переходом экономят действия. Автоматический выбор фотографии и подтверждение упаковки не включены: найденный EAN сам по себе не подтверждает актуальность дизайна фотографии.
3. **Редактор обрезки и маски — следующий кандидат.** Полезен для прозрачных бутылок, белых упаковок и сложного контура. Потребует отдельного UI, истории правок и проверки поведения на разных изображениях; сейчас доступны другой исходник и явный выбор метода фона.

## Рекомендованный ежедневный процесс

- Настройки: Молдова для местных товаров, JPG 1600 px / 95% / локальная нейросеть. Расширенный режим для импортных/редких позиций.
- Заполнить EAN, бренд и фасовку, оба названия при наличии. Не считать внутренний SKU поисковым идентификатором производителя.
- Запустить поиск партии, открыть проверку, выбрать подходящую фотографию и подготовить JPG.
- Сверить вариант, объём, этикетку, крышку, дно и право использования; подтвердить и перейти дальше.
- Для пропусков расширить поиск конкретного SKU или загрузить своё фото. Скачать ZIP после проверки.

## Оставшиеся ограничения

Режим Молдова уменьшает охват, а не гарантирует ускорение каждого запроса: местные источники тоже могут отвечать медленно. Внешние таймауты отражаются в диагностике; повторные запросы к недоступному серверу ограничены временным circuit breaker. Лимит Brave ограничивает одну попытку поиска, не суммарную дневную стоимость. Gemini не запускается автоматически. Обработка и сохранение партий остаются в браузере; серверная очередь, облачная синхронизация и редактор маски относятся к следующему этапу.

## Дополнительная находка в живой проверке

Поиск JLC 0% 500 г по EAN `4840053004404` вернул METRO Moldova с точным GTIN и Linella. На белой упаковке U²-NetP выделила синий рисунок вместо полного пакета — успешный вызов модели сам по себе не подтверждает качество. Добавлена консервативная проверка потери цветных/тёмных деталей: при преимущественно белых краях потеря более 40% заметных деталей отклоняет AI-результат. Изображение не экспортируется; исходник сохраняется, пользователь явно выбирает обрезку светлого фона или другое фото.

Живая повторная проверка: плохая маска остановлена; обрезка светлого фона сохранила полную упаковку. Метод обработки теперь можно выбрать для одного исходника, сохраняя общий профиль остальных SKU. Выбор переживает перезагрузку и учитывается пакетной подготовкой; фактический метод фиксируется в отчёте. Это эвристика для определённого класса ошибок, а не гарантия корректной маски.
