# Оценка технологий поиска для Shelf

Проверено 10 октября 2026. Критерии: бесплатное использование без карты/платного fallback, поиск EAN + RU/RO для Молдовы/СНГ, сохранение фотографии и источника, совместимость с Next.js / Vercel, точность фасовки и варианта упаковки.

Выбранный путь: **прямые каталоги / EAN → SearXNG → Tavily Free при отсутствии пригодных кандидатов → извлечение Product HTML / ограниченный Crawl4AI → прежняя проверка GTIN, бренда, количества и варианта → пользовательское подтверждение**.

Сначала выполняются прямые каталоги. При точном GTIN без конфликтов веб-поиск пропускается, сохраняя квоту. Иначе в расширенном режиме выполняется один настроенный бесплатный веб-провайдер; резерв включается при отказе или отсутствии пригодных кандидатов. При подтверждённом GTIN без конфликтов дополнительные варианты запроса прекращаются. Обрабатываются не более трёх разных карточек на SKU и одной страницы Crawl4AI суммарно. Результат поискового индекса не считается подтверждением GTIN.

Tavily: до поиска проверяются current_plan, plan_limit/plan_usage, paygo_limit/paygo_usage и лимит ключа. При платном плане, положительном paygo, неизвестной схеме или недостаточной квоте поиск не выполняется. Реальный новый Researcher-аккаунт возвращает `paygo_limit: null`, хотя Pay-as-you-go выключен в кабинете. Для этой схемы требуется `TAVILY_FREE_ACCOUNT_CONFIRMED=true`, который задаётся только после проверки выключенного переключателя в аккаунте. Это подтверждение настройки при подключении, а не онлайн-доказательство её неизменности; при изменении биллинга снимите флаг. Неизвестный/отсутствующий paygo по-прежнему блокируется. Остаётся запас 5 кредитов. Это не распределённая квота: гарантия отсутствия платного перерасхода опирается также на отключённый pay-as-you-go в аккаунте. При 20–30 SKU/день и одном basic-запросе на SKU получается 600–900 кредитов за 30 дней без повторных поисков. Два запроса или частые повторы могут исчерпать бесплатный лимит.

Ключи не попадают в клиент, ZIP, отчёт или диагностические ошибки. Клиент получает только признаки настройки; это не обещание доступности сервиса. Brave отключён даже при наличии старого ключа. Нельзя повысить точность совпадения, просто подключив agent framework: все кандидаты проходят существующие строгие проверки, а дизайн упаковки подтверждается человеком.

## Как подключить

### Самый простой вариант на Vercel: Tavily Free

1. Создайте бесплатный Researcher-аккаунт на [app.tavily.com](https://app.tavily.com/), без карты и pay-as-you-go. Условия регистрации принимает владелец аккаунта.
2. После проверки выключенного Pay-as-you-go задайте `TAVILY_FREE_ACCOUNT_CONFIRMED=true` для nullable-схемы. Добавьте `TAVILY_API_KEY` в `.env.local` локально и в серверные переменные Vercel для опубликованной версии. Перезапустите dev / создайте новый deployment.
3. `TAVILY_MAX_QUERIES=1` — отдельный предел. Клиентское значение «6 запросов» не повышает его. Максимум адаптера — 2.
4. В «Источниках» отображается настройка ключа. Реальное подтверждение Free и квоты появится при поиске в диагностике Tavily. Бесплатный ключ нельзя сгенерировать локально вместо провайдера.

### SearXNG + Crawl4AI на собственном ПК

Нужен установленный Docker с Linux-контейнерами и достаточной памятью (Crawl4AI ограничен 2 ГБ, SearXNG — 512 МБ, Chromium также требует shared memory). В проекте нет установки Docker или изменения ОС.

```powershell
npm run search:setup
npm run search:start
npm run dev
```

Setup генерирует секреты в `infra/free-search/.env` и `settings.local.yml` (оба исключены из Git), заполняет только отсутствующие/пустые локальные параметры, сохраняет существующие ключи. Compose закреплён на проверенных registry-digest SearXNG и Crawl4AI v0.9.4. Порты опубликованы только на `127.0.0.1`; это локальная настройка. `npm run search:stop` останавливает эти сервисы.

Для Vercel loopback **не работает**: нужен постоянно доступный собственный сервер с публичным HTTPS на стандартном порту. SearXNG следует защитить reverse proxy с Bearer-токеном (`SEARXNG_API_TOKEN`), Crawl4AI — своим `CRAWL4AI_API_TOKEN`. Задайте `SEARXNG_URL` / `CRAWL4AI_URL` в Vercel, а также точный `CRAWL4AI_ALLOWED_HOSTS`. Не публикуйте локальные контейнеры без TLS и авторизации. Не отключайте штатный контроль исходящих соединений Crawl4AI; приложение тоже проверяет DNS карточки, публичные URL и происхождение HTML. Сервисный API не следует перенаправлениям и фиксирует публичный адрес соединения.

Фотографии из магазинов остаются с неизвестными правами; ни crawler, ни открытая лицензия программы не дают лицензию на изображения. Нельзя использовать SearXNG как обещание обхода блокировок движков или crawler как обещание обхода ограничений магазинов.

## Подтверждённые и неподтверждённые проверки

Контрактные тесты проверяют схемы реальных API, отказ платного Tavily/paygo, квоты, очередность резервов, лимиты карточек, происхождение изображения, конфликт фасовки, точный GTIN, запрещённые адреса, отсутствие браузерного повтора HTTP 403/429, robots-флаг и предел Crawl4AI. Это не живой тест поисковых движков.

В текущей среде Docker отсутствует; контейнеры не запущены. Ключ Tavily получен от владельца; `/usage` проверен: Researcher, 1 000 кредитов, 0 использовано. Выключенный Pay-as-you-go подтверждён в кабинете; nullable-схема учтена отдельным флагом. Подготовка интеграции не равна активации сервиса: приложение честно показывает отсутствие настройки и продолжает прямой поиск. Никакие платные подписки не созданы.

Живой локальный поиск Tavily по Nutella 400 г завершился HTTP 200, вернул карточку товара; 1 basic-запрос = 1 кредит, дополнительно выполнен read-only `/usage`. Поиск EAN, загрузка фото и Gemini на опубликованной версии проверены: правильная масса 400 г → consistent, намеренное несоответствие 200 г → conflict. На Vercel METRO/Bonus ограничивают облачный IP (HTTP 403), другие источники продолжают работу.
