# Разбор похожих открытых проектов

Проверено 12 октября 2026 по GitHub и документации авторов. Изучались доступ к магазинам, извлечение товара из HTML, обработка ограничений частоты и удаление фона. Подходы адаптированы собственным TypeScript-кодом; Python, локальный браузерный сервер и новые обязательные сервисы приложению не добавлены.

## Конкретный сбой METRO и Bonus

Через подключённый Firecrawl получены живые HTML обеих карточек. Ответ HTTP 200 и заголовок «страница не найдена» не были приняты за корректную фотографию. Проверка показала, что `props.initialState.product.productData.product` содержит основной товар: EAN, бренд, название, канонический URL и изображения до 1350×1350.

Новый адаптер читает только этот конкретный объект. Массивы рекомендаций не обходятся. Проверяются известный домен Zakaz, совпадение канонического адреса и GTIN маршрута с записью, а затем EAN, бренд, жирность и фасовка запроса. Противоречие маркированного объёма и названия остаётся видимым для ручной проверки.

Это улучшение работает и при обычном чтении HTML из Vercel/Neon. Подключение Firecrawl к Codex само по себе не выдаёт приложению серверный API-ключ; Firecrawl не объявляется автоматически подключённым runtime-провайдером Vercel.

## Общая пауза источника

К `shelf_source_slots` добавляется `cooldown_until`. При 403/406/429/503 записывается срок следующего допустимого обращения: `Retry-After` при наличии либо одна минута. Диапазон — от секунды до суток. Дальнейшие функции проверяют его атомарно при резервировании запроса и возвращают понятную диагностику, не спят несколько минут внутри Vercel. Пауза 404/401 не создаётся. Отказ базы не скрывает исходную ошибку сервиса.

Изменения проверяются одной пачкой после реализации обоих подходов: типы, серверные и браузерные сценарии, SQL на отдельной ветке Neon и живые данные METRO/Bonus. Полные наборы не запускаются после каждой правки.

Результат пачки: 213 серверных проверок в 25 файлах и 17 браузерных сценариев. В одной новой проверке исправлена тестовая заглушка Promise; повторён только этот файл из пяти тестов. SQL проверен на отдельной ветке Neon: срок 120 секунд не сокращается конкурирующим запросом, исходное и истёкшее ожидание допускают работу, активная пауза отклоняется сразу. Обновлённый исполнитель тестовой ветки (deployment 9) завершил настоящее задание JLC с точным GTIN и фото 1350×1350 из основных данных карточки METRO, несмотря на 403 каталожного API.

Изменения опубликованы на https://shelf-img.vercel.app: Vercel `dpl_GjKzRTsieMcmXeXufndxUn9XFMaj` — READY, основной исполнитель Neon deployment 5 — completed. В дереве опубликованных исходников проверены 92 файла: приватные папки исключены, ONNX-модель присутствует. На основном адресе два настоящих задания без кэша для EAN 4840053000109 и 4840053000444 завершились успешно; точные GTIN подтверждены, фотографии METRO получены с HTTP 200. Время этих конкретных запусков — 10 и 9 секунд. Диагностика второго задания показала действующую общую паузу недоступных источников; получение результата через карточку продолжилось.
