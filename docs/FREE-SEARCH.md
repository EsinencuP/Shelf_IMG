# Бесплатный поиск: выбранный подход

Проверка 10 октября 2026. Ограничение проекта: никаких новых платных подписок, привязки карты или включения биллинга ради поиска.

| Решение                                                        | Что даёт                                                                                                        | Решение для Shelf Studio                                                                                                              |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Прямые публичные каталоги магазинов и производителей           | Фотографии реальных карточек, иногда точный EAN; без ключа поискового посредника                                | Основной способ: Молдова и регион, с диагностикой ограничений источников                                                              |
| Open Food/Beauty/Products/Pet Food Facts, бесплатный UPCitemdb | Поиск по EAN, фотографии с лицензией либо неизвестными правами; ограничения полноты и частоты                   | Подключены; пустой ответ не подтверждает отсутствие товара                                                                            |
| Brave Search, Free credits                                     | В кабинете предложены $5/месяц и 1000 запросов, но для активации требуется действующая карта и принятие условий | Ключ не создан, карта не добавлена, production Brave не подключён                                                                     |
| Google Custom Search JSON API                                  | Ранее давал бесплатную квоту                                                                                    | Закрыт для новых клиентов; не выбран                                                                                                  |
| Gemini 2.5 Flash-Lite + Google Search grounding                | По документации есть free tier                                                                                  | Реальный вызов с текущим новым проектом вернул 404: модель недоступна новым пользователям                                             |
| Gemini 3.1 / 3.5 Flash-Lite                                    | Бесплатная квота проверки изображения; Search grounding не входит в free tier                                   | Gemini оставлен только для ручной проверки фото, без инструмента Google Search                                                        |
| Собственный SearXNG                                            | Открытый поисковый агрегатор, web/images и JSON API                                                             | Возможный следующий этап на собственном сервере. Публичные инстансы не считаются гарантированным бесплатным API для массовой нагрузки |

Для текущего MVP выбран поиск непосредственно в каталогах + открытые базы EAN + локальная сегментация U²-Net. Дополнительный коммерческий поисковый ключ не нужен. Gemini-проект в Google AI Studio проверен: **Free tier**, billing не активировался. При исчерпании квоты приложение показывает ошибку и предлагает ручную проверку; автоматического перехода на другую модель или платный сервис нет. Если владелец впоследствии самостоятельно включит billing этого проекта, условия использования ключа изменятся — приложение не управляет биллингом Google.

Запросы из Vercel проходят с облачных IP; у некоторых источников бывают 403. Прокси для обхода запретов, CAPTCHA и платные обходные сервисы не подключены. Ограничение явно отражается в диагностике. Функции находятся в одном европейском регионе `fra1`, ближе к рынку Молдовы. Для Linella исправлен случай, когда после пустого EAN и румынского названия русское название не пробовалось: теперь используются до трёх вариантов (EAN, RO, RU) с прежней проверкой бренда, фасовки и GTIN.
