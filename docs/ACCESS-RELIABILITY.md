# Доступ к источникам и качество упаковки

Shelf работает на Vercel и Neon Functions. Для использования приложения не нужны localhost, Docker, запущенный worker или установленная нейросеть. Модель, WASM и шрифты загружаются с сайта; подготовка JPG и ZIP выполняется в браузере.

Логин приложения — `admin`. Пароль доступа задаётся переменной `MVP_ACCESS_PASSWORD` отдельно для каждого окружения Vercel. Ключи внешних API и секрет связи с Neon остаются на сервере.

## Как восстанавливается доступ

1. Прямой HTTPS-запрос проверяет публичный URL, DNS и каждый редирект. Поддерживаются identity, gzip, deflate и Brotli; ограничен размер как сетевого, так и распакованного ответа.
2. Для публичного GET из Vercel при 403/406, серверных ошибках или сетевом сбое возможен один резервный запрос через существующую Neon Function `/fetch`. Секрет проверяется до чтения тела. Источник не получает ключи API, пароль Shelf или секрет Function. POST, API с авторизацией, 401, 404 и 429 не повторяются через другой сервер.
3. При закрытом каталожном API поиск использует Brave и Tavily. В режиме «Молдова» резерв включается при недоступном магазине, если разрешён веб-поиск; список принимаемых доменов ограничен подключёнными молдавскими магазинами. Tavily получает приоритет этих доменов и ищет страницы без режима описания изображений, который в живой проверке ухудшал выдачу карточек. В расширенном режиме фотографии общего списка Tavily принимаются только при связи заголовка с одной карточкой. Ограниченный Tavily Extract basic читает до трёх релевантных публичных карточек, отдавая приоритет URL с искомым EAN. Перед извлечением повторно проверяется бесплатная квота и отключённый pay-as-you-go.
4. Из карточек исключаются категории, иконки и изображения рекомендаций. Явный конфликт GTIN или фасовки блокирует также thumbnail выдачи. В маршрутах товаров Zakaz EAN берётся из канонического URL; число в произвольном тексте не считается подтверждением.
   Для Zakaz дополнительно читается только основной товар из `__NEXT_DATA__`: EAN, URL, бренд, фасовка и крупное изображение сверяются с запросом. Это восстанавливает фото даже из HTML с ошибкой отображения, если основные данные товара присутствуют и согласованы; рекомендации не обходятся.
5. Фото скачивается сервером с Referer домена карточки. Неудавшееся прямое превью восстанавливается через этот загрузчик. Превью общего каталога использует авторизованный запрос. Не больше двух восстановлений превью выполняется одновременно в одной вкладке.

Ни один из этих механизмов не гарантирует доступ ко всем сайтам. Живая проверка показала 403 от `stores-api.zakaz.md` и в Vercel, и в Neon; публичная карточка METRO при этом читается через Tavily. Закрытые ресурсы и исчерпанные квоты остаются недоступными, другие источники продолжают поиск. [Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search), [Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract).

## Очередь

Общая таблица ограничений источников сохраняет `cooldown_until` для 403/406/429/503. Учитывается `Retry-After` в секундах или HTTP-date; другие экземпляры Vercel и Neon соблюдают ту же паузу. При 404 весь магазин не блокируется. Подробный разбор использованных подходов открытых проектов: [EXTERNAL-TECHNOLOGY-REVIEW.md](EXTERNAL-TECHNOLOGY-REVIEW.md).

Основной исполнитель — Neon Function с долговечной очередью и арендой задания в PostgreSQL. Если Function не принимает wake-запрос или не настроена, Vercel использует `after()` и ту же аренду для обработки до трёх заданий. Запросу разрешено до 180 секунд. Оставшиеся или прерванные задания сохраняются; открытый сайт повторяет диспетчеризацию. Neon также восстанавливает очередь по своему расписанию. При недоступности Neon и закрытой вкладке непрерывное исполнение большого пакета резервом Vercel не гарантируется. [Срок выполнения after](https://nextjs.org/docs/app/api-reference/functions/after).

## Белые упаковки

Нейросеть может выделить рисунок вместо целого белого пакета. Проверяется не только потеря цветных деталей, но и отсечение светлого силуэта: крышки, верха, низа и боковых краёв. При преимущественно белой границе изображения и заметном расхождении масок применяется обработка белого фона, сохраняющая исходные цвета. Метод записывается как `white-preserved`; причина видна в предупреждении и экспортном отчёте. Отсутствующая или повреждённая модель не подменяется молча другим методом.

Это сохраняет упаковку на белом каталожном фото, но не восстанавливает отсутствующие детали и не заменяет проверку прозрачных/бликующих объектов человеком.

## Форматы источников

JPEG, PNG и WebP проходят проверку и поступают в браузер без повторного кодирования. AVIF, статические GIF и TIFF из внешних URL или ручной загрузки преобразуются на Vercel в PNG с сохранением прозрачности, без уменьшения размеров. Вход и результат ограничены 4 МБ, декодирование — 20 млн пикселей. Анимации, многостраничные файлы и SVG отклоняются. Для миниатюр Zakaz с известным форматом пути загрузчик сначала запрашивает версию 1350×1350 того же asset: тот же домен, хеш каталога и timestamp. При отсутствии, блокировке, повреждении или превышении лимита используется исходная миниатюра. Подписанные URL и другие сайты не переписываются; искусственного увеличения нет. Ручная загрузка дополнительных форматов требует подтверждённого доступа к серверу.
