# Облачный поиск Brave → Tavily

При подключённой `DATABASE_URL` сайт использует общий каталог и очередь PostgreSQL; задания автоматически исполняет Neon Function при настроенных `SHELF_WORKER_URL` и `SHELF_WORKER_SECRET`. Локальный запуск не нужен. [Работа и ограничения](WORKFLOW-DATABASE.md). Без базы Next.js выполняет прежний синхронный поиск на Vercel. Docker и серверный диск не требуются. Сначала прямые каталоги и базы EAN, включая публичный API сканера Состависта (`/api/barcode?c=EAN`); При отсутствии бесконфликтного точного EAN веб-поиск запускается в expanded/useWeb; в режиме «Молдова» разрешённый веб-резерв запускается при недоступности подключённого магазина и принимает только карточки этих молдавских источников. Другой GTIN, бренд или фасовка отклоняются; внутреннее противоречие единиц при точном EAN и согласующемся названии сохраняется для ручной проверки. Brave Web Search — основной, Tavily Free — резерв. Gemini остаётся отдельной ручной проверкой. HTML читается HTTPS-запросом с поддержкой сжатия; недоступные публичные карточки могут быть прочитаны через Tavily Extract basic. Приоритет получают карточки с EAN, исключаются изображения рекомендаций. Каталоги могут отвечать 403 из облака даже когда доступны локально; поиск продолжает работу с другими источниками.

## Переменные

- `MVP_ACCESS_PASSWORD` обязателен в production.
- `BRAVE_SEARCH_API_KEY`: ключ именно Brave Search, не Tavily.
- `BRAVE_MAX_QUERIES=2`: максимум четыре запроса на SKU; серверный и пользовательский пределы могут уменьшить число.
- `BRAVE_FREE_ONLY_CONFIRMED=false` по умолчанию. Нельзя включать без проверки конкретного аккаунта.
- `BRAVE_FREE_ONLY_KEY_SHA256`: SHA-256 ключа, для которого подтверждены ограничения. Ротация ключа выключает прежнее подтверждение.
- `TAVILY_API_KEY`, `TAVILY_FREE_ACCOUNT_CONFIRMED=true`: Researcher/Free, pay-as-you-go выключен. Перед поиском проверяется `/usage`; basic, один запрос по умолчанию (`TAVILY_MAX_QUERIES`, максимум два).
- `GEMINI_API_KEY` необязателен и не вызывается автоматически.

## Запрет платного расхода Brave

Brave сейчас документирует prepaid Search и бесплатный ежемесячный кредит. Приложение не покупает кредиты, не включает автопополнение и не меняет тариф. Но оно не имеет API для достоверного чтения всех платёжных настроек аккаунта. Поэтому пока оператор не проверит отсутствие расходуемого платного баланса, автопополнения/платного превышения и поведение после исчерпания бесплатного кредита, вызовы Brave заблокированы. Просто наличие ключа не включает поиск.

После проверки аккаунта оператор задаёт `BRAVE_FREE_ONLY_CONFIRMED=true` и SHA-256 именно этого ключа в серверных env. Контроль аккаунта у провайдера остаётся обязательным: эти переменные фиксируют подтверждение, не являются самостоятельной проверкой billing. Память процесса и лимит SKU не гарантируют глобальную квоту между функциями Vercel. При отсутствии подтверждения, ошибке или исчерпании Brave пробуется Tavily Free. Платный fallback отсутствует.

Официальные условия: https://api-dashboard.search.brave.com/documentation/pricing

## Контроль качества и скорость

Не более шести релевантных карточек проверяется на SKU через оба веб-провайдера вместе. Пустой ответ Brave без поля `web` считается успешной пустой выдачей; поиск продолжается по названию. Tavily использует название, если оно известно, вместо повторения неудачного запроса по EAN. Если введён только EAN, справочник barcode-list.ru может определить название по явно указанной связи с этим кодом; это не подтверждение фотографии. HTML-карточки поддерживают Product JSON-LD и Open Graph. Изображение выдачи — кандидат, оно не подтверждает штрихкод. Конфликт GTIN/фасовки карточки запрещает использовать её thumbnail как обход проверки. При точном EAN цикл и резерв останавливаются. Редиректы API с секретными заголовками запрещены, фотографии и карточки проходят прежнюю защиту DNS/IP.

Региональные источники запускаются параллельно; запросы к одному хосту по-прежнему сериализуются `paced`. Ускорение в конкретное число раз не измерено и не обещается.

Временный кэш поиска — ограниченная память процесса и может исчезнуть при холодном старте. Подтверждённые JPEG и задания дополнительно сохраняются в PostgreSQL. История целых партий и рабочие фотографии остаются в браузере. Явный повторный поиск SKU обходит и кэш, и общий каталог, чтобы можно было найти новую упаковку. Старые партии сохраняют свои параметры, прежнее поле политики локальных источников игнорируется.

Предыдущие локальные данные и код сохранены в игнорируемом `.local-archive/pre-cloud-2026-10-11`, в деплой не входят. Не запускайте архивные процессы для новой схемы.

## Проверки и деплой

Последовательно: `npm run typecheck`, `npm run test`, `npm run format:check`, `npm run build`; браузерные проверки — `npm run test:e2e`. На Vercel установить env и создать новый deployment. Автотесты проверяют контракты без реального расхода Brave; живую работу можно проверить только после настройки ключа и запрета платного расхода в аккаунте.
