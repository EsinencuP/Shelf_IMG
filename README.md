# Shelf Studio — MVP

Веб-инструмент для подготовки фотографий товаров для планограмм Shelf:

**Excel/CSV → поиск кандидатов → проверка SKU → выделение упаковки в браузере → белый фон и плотная прямоугольная обрезка → JPG + ZIP + отчёт.**

Резервный доступ, облачная очередь и обработка белых упаковок описаны в [ACCESS-RELIABILITY.md](docs/ACCESS-RELIABILITY.md).

## Запуск

Веб-приложение работает на Vercel. Общий каталог, очередь и автоматический облачный исполнитель подключены к Neon Free; локальный запуск не нужен. Поиск идёт каскадом: подтверждённый каталог → точный EAN → тематические каталоги → магазины → Brave → Tavily Free. Найденный точный кандидат останавливает резервные запросы. [Настройка без платного расхода](docs/CLOUD-SEARCH.md), [каталог и очередь](docs/WORKFLOW-DATABASE.md).

Требуется Node.js **24 LTS** и npm.

```powershell
cd D:\Imensitate\Shelf
npm ci
npm run dev
```

Откройте <http://localhost:3000>. Зависимости могут запрашивать сетевой доступ во время установки. `postinstall` копирует WASM из установленной версии ONNX Runtime; модель U²-Net уже включена в проект. Если модель отсутствует или повреждена:

```powershell
npm run setup:model
```

Скрипт скачивает закреплённый файл и проверяет SHA-256. Обработка не использует платные AI API и сохраняет исходную упаковку; генеративной дорисовки нет.

## Локальный режим на домашнем ПК

После установки зависимостей подготовьте `.env.local`, если файла ещё нет:

```powershell
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
npm run start:local
```

В `.env.local` должен быть задан `MVP_ACCESS_PASSWORD`: для production-режима он
обязателен и на локальном ПК. В приложении используйте логин `admin` и этот пароль.
Next.js также читает `.env.production.local`, если он есть: его значения имеют
приоритет над `.env.local`; переменные окружения процесса имеют приоритет над обоими.

`start:local` сначала выполняет сборку, затем запускает production-сервер на
<http://localhost:3000>. Он привязан к `localhost`; порт 3000 должен быть свободен.
При ошибке сборки сервер не запускается. Для остановки нажмите **Ctrl+C** в терминале.
Режим разработки с автоперезагрузкой доступен через `npm run dev`.

Чтобы поиск из интерфейса выполнялся полностью на ПК без общей БД и облачной
очереди, оставьте `DATABASE_URL`, `SHELF_WORKER_URL` и `SHELF_WORKER_SECRET` пустыми
в используемом локальном окружении. Если они настроены, приложение сохраняет
обычную работу с общим каталогом и исполнителем.

Проверка прямого доступа к каталогам с IP этого компьютера — в другом терминале:

```powershell
npm run probe
```

Команда печатает таблицу и сохраняет `probe-report.json`. Проверьте `httpStatus`
для **METRO Moldova** и **Bonus Moldova**: ожидается **200**, если текущий домашний
IP не ограничен источником. Нулевое число фото при HTTP 200 — отдельный результат,
а не ошибка соединения. При HTTP 403/429 или `timeout` смотрите причину в отчёте.
Probe работает напрямую и не требует запущенного интерфейса; его настройки
берутся из окружения и `.env.local`. [Подробности проверки](docs/PROBE-SOURCES.md).

## Relay на домашнем ПК

`npm run relay` запускает отдельный Node-сервер на `127.0.0.1:8787` без Docker.
Он предоставляет защищённые Bearer-токеном `GET /health` и `POST /fetch`, загружает
только публичные HTTPS-адреса из allowlist и ограничивает размер ответа.
[Настройка `.env.local` и проверки curl](infra/relay/README.md).

## Что работает

- Импорт `.xlsx` первого листа и UTF-8 CSV, ручное сопоставление колонок, сохранение текстовых SKU/EAN и предупреждения о проблемах Excel.
- Форма «Один артикул» без Excel: SKU и EAN или название RU/RO; бренд, фасовка, внутренний код и габариты необязательны. Создаётся отдельная сохранённая партия и автоматически запускается поиск.
- До 1 000 позиций, 50 колонок и 10 МБ на исходный файл. Для поиска укажите SKU и валидный GTIN или название RU/RO. Строки с ошибочным GTIN сохраняют исходный код. Если есть название, можно отдельно выбрать «Искать по названию» в карточке.
- Кнопка «Фото поставщика из папки» прикрепляет JPG, PNG и WebP по имени файла, совпавшему с SKU, внутренним кодом или GTIN. Проверьте упаковку и права перед экспортом. Украина и Румыния доступны как рынки поставщика в расширенном поиске.
- Поиск для рынка Молдовы: прямые публичные каталоги METRO Moldova, Bonus, Linella и производителя Bucuria; дополнительно METRO Ukraine, NOVUS, Auchan Ukraine и Таврия В. Используются EAN и наименования RU/RO, изображения карточек и данные фасовки. Доступность и число найденных фото по каждому источнику сохраняются в диагностике.
- Базы штрихкодов: Open Food Facts, Open Beauty Facts, Open Products Facts, Open Pet Food Facts и UPCitemdb. Пустая база не гарантирует отсутствие товара. Бесплатный UPCitemdb ограничен 100 запросами в день и частотой 1 запрос / 10 секунд; превышение квоты показывается, платного перехода нет.
- Проверка GTIN, конфликтов бренда/фасовки/мультипака по данным источника. Кандидаты требуют визуального подтверждения; AI-score не используется как доказательство SKU.
- Выбор найденной фотографии, собственный JPG/PNG/WebP/AVIF/статический GIF/TIFF или публичная HTTPS-ссылка. AVIF, GIF и TIFF преобразуются облачным загрузчиком в PNG с сохранением прозрачности.
- Реальная локальная нейросеть U²-NetP через ONNX/WASM; альтернативный явный режим обрезки белого фона. Модель и шрифты загружаются с самого приложения.
- Непрозрачный JPG на белом фоне, прямоугольник по границам маски упаковки, сохранённые пропорции; максимальная сторона 1200/1600/2400 px, без увеличения небольшого оригинала.
- Предпросмотр до/после, предупреждения о контуре, отдельное подтверждение соответствия товара и прав на фотографию.
- ZIP с `images/*.jpg`, `report.xlsx` по всем строкам, `manifest.json` и `attributions.txt`. Имена безопасны для Windows, коллизии разрешаются с сохранением соответствия в отчёте. При выборе внутреннего кода пустой код заменяется SKU.
- Реальная история партий с Blob-изображениями в **IndexedDB**; восстановление незавершённых состояний после перезагрузки.
- Дополнительная Gemini-проверка видимых атрибутов, если подключён ключ. Конфликт сохраняется в партии; платного fallback нет.

## Как пользоваться и выбирать параметры

1. Откройте **Настройки**. Для обычного поиска в местных магазинах выберите **Молдова**, для редких/импортных товаров — **Расширенный** (по умолчанию сохраняется полный охват). Режим Молдова использует METRO Moldova, Bonus, Linella, Bucuria и Open Food Facts по EAN; при недоступности магазина и включённом веб-поиске запускает резерв только для подключённых молдавских сайтов. Зарубежные каталоги пропускаются. Это сокращает запросы, но может дать меньше кандидатов.
2. Для Shelf оставьте локальную нейросеть, длинную сторону 1600 px и качество JPEG 95%. Для исходников с уже чистым белым фоном можно явно выбрать обрезку светлого фона. 90% уменьшает файлы, 100% увеличивает их; низкое разрешение оригинала не восстанавливается.
3. Добавьте Excel/CSV или **Один артикул**, запустите поиск. В карточке конкретного SKU доступны повторный поиск и, в режиме Молдова, **Расширить поиск для SKU**. В разделе **Поиск на рынке поставщика** можно выбрать Украину или Румынию и указать название на языке поставщика. Настройки действуют для запроса по этой позиции. Параметры последнего поиска каждой позиции сохраняются в ZIP manifest.
4. Выберите фото, нажмите **Подготовить JPG**, проверьте фасовку/этикетку/контур и право использования. **Подтвердить и перейти дальше** открывает следующую неподтверждённую позицию; **Следующий SKU** позволяет отложить текущую. Gemini остаётся отдельной ручной проверкой.
5. Скачайте ZIP. В него попадают только подтверждённые фотографии; отчёт содержит все позиции, включая пропуски и ошибки.

При объёме фотографий от 32 МиБ Chrome и Edge предлагают выбрать файл и записывают ZIP на диск по частям. В остальных браузерах доступно обычное скачивание. Максимальный размер архива при потоковой записи — 4 ГБ.

Настройки сохраняются в `localStorage` без паролей/ключей, даже до создания партии. Новые партии используют эти defaults; старые сохраняют собственный профиль в IndexedDB. Изменения в Настройках применяются к текущей партии и запоминаются для следующих. При смене размера, JPEG-качества или метода ранее подготовленные JPG и их подтверждения сбрасываются; исходные фото сохраняются. Нажмите **Подготовить JPG** и подтвердите новый результат. Смена имени файлов не требует повторной обработки.

В карточке есть **Обработка этой фотографии**: настройки партии, светлый фон или локальная нейросеть. Выбор запоминается для данного исходника и используется также пакетной обработкой, не меняя остальные SKU. Новый исходник сбрасывает индивидуальный выбор; смена метода в настройках партии возвращает всем строкам общий метод. На фото с преимущественно белыми краями дополнительная проверка отклоняет AI-маску, если она удаляет большую часть заметных цветных/тёмных деталей. Например, модель может выделить рисунок на белом пакете вместо всей упаковки. При преимущественно белых краях и отсечении деталей или силуэта применяется сохранение полного контура в режиме white-preserved; причина показывается в предупреждении. Если восстановление небезопасно, JPG не создаётся — выберите другой метод или исходник. Проверка не заменяет визуальный контроль контура и не покрывает все виды ошибок.

Результаты аудита UI и выбранные улучшения: `docs/UI-AUDIT.md`.

## Настройка серверных API

Скопируйте `.env.example` в `.env.local` и заполните только необходимые поля. Не коммитьте `.env.local`.

| Переменная                      | Назначение                                                                                                       |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `MVP_ACCESS_PASSWORD`           | Пароль доступа к API. **Обязателен в production**; без него поиск, image proxy и Gemini возвращают 503.          |
| `OPENFOODFACTS_USER_AGENT`      | Имя приложения с вашей контактной информацией или URL для запросов Open Food Facts.                              |
| `TAVILY_API_KEY`                | Необязательный Tavily Free/Researcher; платный тариф или paygo блокируются адаптером.                            |
| `TAVILY_FREE_ACCOUNT_CONFIRMED` | `true` только после проверки выключенного Pay-as-you-go в кабинете. Нужен для реальной nullable-схемы `/usage`.  |
| `GEMINI_API_KEY`                | Необязательная визуальная проверка. Условия, доступность и бесплатная квота зависят от вашего проекта и региона. |
| `GEMINI_MODEL`                  | По умолчанию `gemini-3.1-flash-lite`; допускается также `gemini-3.5-flash-lite`.                                 |

Если сервер защищён, откройте **Настройки → Доступ к серверу**, введите пароль и нажмите «Подключиться». Пароль хранится только в памяти вкладки; после перезагрузки его потребуется ввести снова. Используйте HTTPS при размещении в интернете.

Gemini получает только необходимое изображение и публичные атрибуты товара, без внутренних SKU/кодов и исходного Excel. Приложение не включает billing и не меняет тарифы провайдера. Если вы используете ключ платного проекта, действуют условия именно этого проекта; бесплатность API приложение не гарантирует.

## Размещение на Vercel

Проект Vercel: **shelf-img**, основной адрес: <https://shelf-img.vercel.app>, Git-репозиторий: <https://github.com/EsinencuP/Shelf_IMG>, production-ветка: **main**. Стек: **Next.js**, Node.js 24, build `npm run build`, install `npm ci`. Для сверки сборки используйте `/api/config`: `build.commit` показывает заявленный Git SHA, `build.fingerprint` — SHA-256 исходников приложения, публичных ассетов и конфигурации на этапе сборки, `build.deploymentId` — идентификатор деплоя. В dev сведения о сборке пусты.

Пароль приложения и Gemini задаются серверными секретами Vercel. Для доступа к API откройте **Настройки → Доступ к серверу** и подключитесь с паролем приложения. Локальные `.env.local` / `.env.production.local` и служебная папка `.vercel` исключены из Git. Neon хранит подтверждённые фотографии и задания; история партий и рабочие Blob остаются в IndexedDB.

Серверные функции размещаются в одном регионе **Frankfurt (`fra1`)**, ближе к молдавским и европейским каталогам. Один регион доступен и на Hobby; платный multi-region/failover не используется. Публичный GET при отдельных сетевых отказах может быть повторён через существующую Neon Function. Доступность сторонних каталогов проверяйте по диагностике: отдельные источники могут ограничивать запросы из облачных сетей.

Excel, обработка и ZIP находятся в браузере. Подтверждённые JPEG и задания поиска сохраняются в PostgreSQL; постоянная файловая система Vercel не требуется. Очередь автоматически исполняется в Neon Functions; `npm run worker` оставлен для отладки; при недоступности Neon резервные задания автоматически выполняет Vercel. Без `DATABASE_URL` доступен прежний синхронный режим `/api/search`.

## Ограничения MVP

- **Вкладка должна оставаться открытой во время обработки.** Сохранённые результаты переживают перезагрузку; непрерывного серверного workflow после закрытия вкладки пока нет.
- История принадлежит одному браузеру и устройству. Очистка данных сайта удаляет её; скачивайте ZIP как резервную копию. Нет облачной синхронизации, индивидуальных аккаунтов и совместного редактирования.
- Подтверждение каждого результата человеком обязательно. Нет обещания безошибочного автоматического выбора упаковки; версия дизайна и рынок могут отличаться даже при совпадении GTIN.
- Белая/прозрачная упаковка, блики, тонкие части и тени могут требовать другого исходника. Нет встроенного редактора маски; доступны смена фотографии и повторная обработка.
- Физические габариты сохраняются отдельными данными и не выводятся из пикселей. Готовый JPG нужно проверить импортом в вашу конкретную версию Shelf.
- Canvas использует JPEG-энкодер браузера; baseline/4:4:4/ICC не гарантируются между браузерами. Вблизи контура возможны небольшие отклонения от белого из-за JPEG-сжатия.
- Лимиты внешних источников регулируются их аккаунтами. При подключённой PostgreSQL интервалы запросов общие между исполнителями и Vercel; месячный расход ограничивается в аккаунтах провайдеров. Без базы интервалы действуют внутри процесса. Brave требует лимит Free, Tavily — выключенный Pay-as-you-go.
- Если каталог не отвечает или возвращает временный сбой, повторные обращения к его серверу пропускаются на 60 секунд в текущем Node-процессе. Другие источники продолжают поиск; причина отображается в диагностике.
- Open Food Facts предоставляет изображения по своей лицензии; атрибуция сохраняется. Права сторонних сайтов неизвестны, пока пользователь не подтвердит основание использования. Подтверждение не создаёт лицензию.

## Проверки

```powershell
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Unit/integration-тесты покрывают импорт, контроль GTIN, конфликты товаров, SSRF/DNS/redirects, доступ к API, ZIP/отчёт/коллизии, маски/геометрию/форматы. Browser-тесты проходят настоящий XLSX/CSV → загрузка фото → локальная нейросеть или белый режим → подтверждение → IndexedDB reload → ZIP, а также отказ отсутствующей модели и доступность интерфейса. Геометрические изображения в тестах — технические fixtures, не реальные товары каталога.

Автоматические тесты используют подменённые upstream-ответы для стабильности. Живые проверки 10 октября 2026: JLC по EAN в METRO Moldova; JLC по названию в Linella и Bonus; ROSHEN Konafetto в молдавских магазинах. Gemini с локальным ключом дополнительно проверен на реальной фотографии Nutella. Новые веб-провайдеры проверены контрактными тестами; их живая активация требует собственного сервера или ключа Tavily Free.

## Следующий этап

Подключён Neon Free: общий каталог подтверждённых JPEG, долговечная очередь, общие интервалы запросов к источникам. Следующие отдельные задачи — индивидуальная авторизация, синхронизация целых партий, постоянное размещение исполнителя и вынесение больших изображений в объектное хранилище.

Лицензии и происхождение модели описаны в `THIRD_PARTY.md`; лицензия U²-Net находится в `public/models/`.
