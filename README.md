# Shelf Studio — MVP

Веб-инструмент для подготовки фотографий товаров для планограмм Shelf:

**Excel/CSV → поиск кандидатов → проверка SKU → локальное выделение упаковки → белый фон и плотная прямоугольная обрезка → JPG + ZIP + отчёт.**

## Запуск

Требуется Node.js **24 LTS** и npm.

```powershell
cd D:\Imensitate\Shelf
npm ci
npm run dev
```

Откройте <http://localhost:3000>. Зависимости могут запрашивать сетевой доступ во время установки. `postinstall` копирует WASM из установленной версии ONNX Runtime; модель U²-Net уже включена в проект. Если модель отсутствует или повреждена:

```powershell
npm run setup:model
```

Скрипт скачивает закреплённый файл и проверяет SHA-256. Обработка не использует платные AI API и сохраняет исходную упаковку; генеративной дорисовки нет.

## Что работает

- Импорт `.xlsx` первого листа и UTF-8 CSV, ручное сопоставление колонок, сохранение текстовых SKU/EAN и предупреждения о проблемах Excel.
- Форма «Один артикул» без Excel: SKU и EAN или название RU/RO; бренд, фасовка, внутренний код и габариты необязательны. Создаётся отдельная сохранённая партия и автоматически запускается поиск.
- До 500 позиций, 50 колонок и 10 МБ на исходный файл; защита от чрезмерного распаковывания XLSX.
- Поиск для рынка Молдовы: прямые публичные каталоги METRO Moldova, Bonus, Linella и производителя Bucuria; дополнительно METRO Ukraine, NOVUS, Auchan Ukraine и Таврия В. Используются EAN и наименования RU/RO, изображения карточек и данные фасовки. Доступность и число найденных фото по каждому источнику сохраняются в диагностике.
- Базы штрихкодов: Open Food Facts, Open Beauty Facts, Open Products Facts, Open Pet Food Facts и UPCitemdb. Пустая база не гарантирует отсутствие товара. Бесплатный UPCitemdb ограничен 100 запросами в день и частотой 1 запрос / 10 секунд; превышение квоты показывается, платного перехода нет.
- Бесплатный общий веб-поиск: SearXNG на собственном сервере, резерв Tavily Free (1 000 кредитов/месяц без карты). Tavily проверяет тариф и отключённый pay-as-you-go до запроса; basic и один запрос/SKU по умолчанию. Строгие проверки SKU сохраняются. Для динамических карточек подключается отдельный Crawl4AI без LLM. [Оценка всех шести технологий и подключение](docs/SEARCH-TECHNOLOGY-AUDIT.md).
- Legacy-ключ Brave не используется: общий поиск работает только через указанные бесплатные источники.
- Проверка GTIN, конфликтов бренда/фасовки/мультипака по данным источника. Кандидаты требуют визуального подтверждения; AI-score не используется как доказательство SKU.
- Выбор найденной фотографии, собственный JPG/PNG/WebP или публичная HTTPS-ссылка.
- Реальная локальная нейросеть U²-NetP через ONNX/WASM; альтернативный явный режим обрезки белого фона. Модель и шрифты загружаются с самого приложения.
- Непрозрачный JPG на белом фоне, прямоугольник по границам маски упаковки, сохранённые пропорции; максимальная сторона 1200/1600/2400 px, без увеличения небольшого оригинала.
- Предпросмотр до/после, предупреждения о контуре, отдельное подтверждение соответствия товара и прав на фотографию.
- ZIP с `images/*.jpg`, `report.xlsx` по всем строкам, `manifest.json` и `attributions.txt`. Имена безопасны для Windows, коллизии разрешаются с сохранением соответствия в отчёте. При выборе внутреннего кода пустой код заменяется SKU.
- Реальная история партий с Blob-изображениями в **IndexedDB**; восстановление незавершённых состояний после перезагрузки.
- Дополнительная Gemini-проверка видимых атрибутов, если подключён ключ. Конфликт сохраняется в партии; платного fallback нет.

## Как пользоваться и выбирать параметры

1. Откройте **Настройки**. Для обычного поиска в местных магазинах выберите **Молдова**, для редких/импортных товаров — **Расширенный** (по умолчанию сохраняется полный охват). Режим Молдова использует METRO Moldova, Bonus, Linella, Bucuria и Open Food Facts по EAN; пропускает зарубежные каталоги, дополнительные базы и общий веб-поиск. Это сокращает запросы, но может дать меньше кандидатов.
2. Для Shelf оставьте локальную нейросеть, длинную сторону 1600 px и качество JPEG 95%. Для исходников с уже чистым белым фоном можно явно выбрать обрезку светлого фона. 90% уменьшает файлы, 100% увеличивает их; низкое разрешение оригинала не восстанавливается.
3. Добавьте Excel/CSV или **Один артикул**, запустите поиск. В карточке конкретного SKU доступны повторный поиск и, в режиме Молдова, **Расширить поиск для SKU**. Это расширяет только данный запрос. Последний режим каждой позиции сохраняется в ZIP manifest.
4. Выберите фото, нажмите **Подготовить JPG**, проверьте фасовку/этикетку/контур и право использования. **Подтвердить и перейти дальше** открывает следующую неподтверждённую позицию; **Следующий SKU** позволяет отложить текущую. Gemini остаётся отдельной ручной проверкой.
5. Скачайте ZIP. В него попадают только подтверждённые фотографии; отчёт содержит все позиции, включая пропуски и ошибки.

Настройки сохраняются в `localStorage` без паролей/ключей, даже до создания партии. Новые партии используют эти defaults; старые сохраняют собственный профиль в IndexedDB. Изменения в Настройках применяются к текущей партии и запоминаются для следующих. При смене размера, JPEG-качества или метода ранее подготовленные JPG и их подтверждения сбрасываются; исходные фото сохраняются. Нажмите **Подготовить JPG** и подтвердите новый результат. Смена имени файлов не требует повторной обработки.

Веб-поиск можно выключить отдельно. Лимит 1/2/4/6 вариантов запроса ограничивает SearXNG; серверный `SEARCH_MAX_WEB_QUERIES` может уменьшить его. Tavily имеет отдельный предел `TAVILY_MAX_QUERIES=1` и проверку Free-квоты. Без настроенного сервиса вызовов веб-поиска нет. При точном EAN без конфликтов в прямом каталоге веб-поиск пропускается. Лимит относится к одной попытке; повторный поиск может снова расходовать квоту.

В карточке есть **Обработка этой фотографии**: настройки партии, светлый фон или локальная нейросеть. Выбор запоминается для данного исходника и используется также пакетной обработкой, не меняя остальные SKU. Новый исходник сбрасывает индивидуальный выбор; смена метода в настройках партии возвращает всем строкам общий метод. На фото с преимущественно белыми краями дополнительная проверка отклоняет AI-маску, если она удаляет большую часть заметных цветных/тёмных деталей. Например, модель может выделить рисунок на белом пакете вместо всей упаковки. В этом случае JPG не создаётся; выберите светлый фон явно или другой исходник. Проверка не заменяет визуальный контроль контура и не покрывает все виды ошибок.

Результаты аудита UI и выбранные улучшения: `docs/UI-AUDIT.md`.

## Настройка серверных API

Скопируйте `.env.example` в `.env.local` и заполните только необходимые поля. Не коммитьте `.env.local`.

| Переменная                            | Назначение                                                                                                                |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `MVP_ACCESS_PASSWORD`                 | Пароль доступа к API. **Обязателен в production**; без него поиск, image proxy и Gemini возвращают 503.                   |
| `OPENFOODFACTS_USER_AGENT`            | Имя приложения с вашей контактной информацией или URL для запросов Open Food Facts.                                       |
| `SEARXNG_URL`                         | Адрес собственного SearXNG с включённым JSON. HTTP loopback допускается только в dev, production требует публичный HTTPS. |
| `SEARXNG_API_TOKEN`                   | Bearer-токен reverse proxy SearXNG, серверный секрет.                                                                     |
| `TAVILY_API_KEY`                      | Необязательный Tavily Free/Researcher; платный тариф или paygo блокируются адаптером.                                     |
| `TAVILY_FREE_ACCOUNT_CONFIRMED`       | `true` только после проверки выключенного Pay-as-you-go в кабинете. Нужен для реальной nullable-схемы `/usage`.           |
| `TAVILY_MAX_QUERIES`                  | 1 basic-запрос/SKU по умолчанию, максимум 2.                                                                              |
| `CRAWL4AI_URL` / `CRAWL4AI_API_TOKEN` | Адрес и токен собственного Crawl4AI v0.9.4.                                                                               |
| `CRAWL4AI_ALLOWED_HOSTS`              | Точный список разрешённых доменов через запятую. Без него браузерное извлечение выключено.                                |
| `GEMINI_API_KEY`                      | Необязательная визуальная проверка. Условия, доступность и бесплатная квота зависят от вашего проекта и региона.          |
| `GEMINI_MODEL`                        | По умолчанию `gemini-3.1-flash-lite`; допускается также `gemini-3.5-flash-lite`.                                          |

Если сервер защищён, откройте **Настройки → Доступ к серверу**, введите пароль и нажмите «Подключиться». Пароль хранится только в памяти вкладки; после перезагрузки его потребуется ввести снова. Используйте HTTPS при размещении в интернете.

Gemini получает только необходимое изображение и публичные атрибуты товара, без внутренних SKU/кодов и исходного Excel. Приложение не включает billing и не меняет тарифы провайдера. Если вы используете ключ платного проекта, действуют условия именно этого проекта; бесплатность API приложение не гарантирует.

## Размещение на Vercel

Проект Vercel: **shelf-img**, основной адрес: <https://shelf-img.vercel.app>, Git-репозиторий: <https://github.com/EsinencuP/Shelf_IMG>, production-ветка: **main**. Стек: **Next.js**, Node.js 24, build `npm run build`, install `npm ci`. После push проверяйте, что production deployment находится в READY и его commit SHA совпадает с текущей веткой.

Пароль приложения и Gemini задаются серверными секретами Vercel. Для доступа к API откройте **Настройки → Доступ к серверу** и подключитесь с паролем приложения. Локальные `.env.local` / `.env.production.local` и служебная папка `.vercel` исключены из Git. Облачная база и синхронизация партий пока не подключены.

Серверные функции размещаются в одном регионе **Frankfurt (`fra1`)**, ближе к молдавским и европейским каталогам. Один регион доступен и на Hobby; платные multi-region/failover и прокси не используются. Доступность сторонних каталогов проверяйте по диагностике: отдельные источники могут ограничивать запросы из облачных сетей.

Перед публичным размещением задайте `MVP_ACCESS_PASSWORD` и реальный контакт `OPENFOODFACTS_USER_AGENT` в переменных Vercel. SearXNG, Tavily Free, Crawl4AI и Gemini необязательны. `/api/image` ограничен 4 000 000 байтами, декодирование — 20 мегапикселями. Прокси проверяет публичные DNS/IP, фиксирует проверенный адрес соединения и повторно проверяет перенаправления. SVG/анимированные изображения не обрабатываются.

В MVP нет серверных записей партий и зависимости от постоянной файловой системы Vercel. Изображения, Excel, обработка и ZIP находятся в браузере; сервер выполняет ограниченные запросы поиска/загрузки/проверки.

## Ограничения MVP

- **Вкладка должна оставаться открытой во время обработки.** Сохранённые результаты переживают перезагрузку; непрерывного серверного workflow после закрытия вкладки пока нет.
- История принадлежит одному браузеру и устройству. Очистка данных сайта удаляет её; скачивайте ZIP как резервную копию. Нет облачной синхронизации, индивидуальных аккаунтов и совместного редактирования.
- Подтверждение каждого результата человеком обязательно. Нет обещания безошибочного автоматического выбора упаковки; версия дизайна и рынок могут отличаться даже при совпадении GTIN.
- Белая/прозрачная упаковка, блики, тонкие части и тени могут требовать другого исходника. Нет встроенного редактора маски; доступны смена фотографии и повторная обработка.
- Физические габариты сохраняются отдельными данными и не выводятся из пикселей. Готовый JPG нужно проверить импортом в вашу конкретную версию Shelf.
- Canvas использует JPEG-энкодер браузера; baseline/4:4:4/ICC не гарантируются между браузерами. Вблизи контура возможны небольшие отклонения от белого из-за JPEG-сжатия.
- Лимиты внешних источников и стоимость регулируются их аккаунтами. Ограничитель MVP действует внутри одного Node-процесса, а не как общая дневная квота между экземплярами Vercel. Не считайте приложение гарантией нулевых расходов для подключённых платных ключей.
- Если каталог не отвечает или возвращает временный сбой, повторные обращения к его серверу пропускаются на 60 секунд в текущем Node-процессе. Другие источники продолжают поиск; причина отображается в диагностике.
- Open Food Facts предоставляет изображения по своей лицензии; атрибуция сохраняется. Права сторонних сайтов неизвестны, пока пользователь не подтвердит основание использования. Подтверждение не создаёт лицензию.

## Проверки

```powershell
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Unit/integration-тесты покрывают импорт, контроль GTIN, конфликты товаров, SSRF/DNS/redirects, доступ к API, ZIP/отчёт/коллизии, маски/геометрию/форматы. Browser-тесты проходят настоящий XLSX/CSV → загрузка фото → локальная нейросеть или белый режим → подтверждение → IndexedDB reload → ZIP, а также отказ отсутствующей модели и доступность интерфейса. Геометрические изображения в тестах — технические fixtures, не реальные товары каталога.

Автоматические тесты используют подменённые upstream-ответы для стабильности. Живые проверки 10 октября 2026: JLC по EAN в METRO Moldova; JLC по названию в Linella и Bonus; ROSHEN Konafetto в молдавских магазинах. Gemini с локальным ключом дополнительно проверен на реальной фотографии Nutella. Новые веб-провайдеры проверены контрактными тестами; их живая активация требует собственного сервера или ключа Tavily Free.

## Следующий этап

После предоставления доступа выбрать Neon или Supabase и подключить индивидуальную авторизацию, облачное хранилище оригиналов/результатов, долговечную очередь, общие квоты и синхронизацию партий. Это отдельный этап; в текущем MVP облачные сервисы не провизионированы.

Лицензии и происхождение модели описаны в `THIRD_PARTY.md`; лицензия U²-Net находится в `public/models/`.
